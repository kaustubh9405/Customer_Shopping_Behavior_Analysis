# Customer Shopping Behavior Analysis

## 📌 Overview

**Customer Shopping Behavior Analysis** is a data analytics project focused on exploring customer shopping data, identifying patterns, and generating meaningful business insights through data analysis and visualization.

The project follows an end-to-end data analytics workflow, starting with data loading and exploratory data analysis (EDA), followed by data cleaning, SQL-based analysis, and interactive dashboard development using Power BI.

The primary objective is to transform raw customer shopping data into meaningful insights that can support data-driven business decisions.

## 📂 Dataset

The project uses a customer shopping behavior dataset for analysis.

The dataset is loaded and processed using Python to understand its structure, identify data quality issues, and prepare it for further analysis.

**Dataset Operations:**
- Loading the dataset into Python.
- Understanding data structure and attributes.
- Identifying missing values and duplicate records.
- Exploring customer shopping patterns.
- Preparing clean data for SQL analysis and visualization.

*Note: Refer to the project files for the original dataset and its details.*
